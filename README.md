## Git & GitHub

### [2026-11-09] Konsep VCS Terdistribusi & Forking
- **VCS Terdistribusi:** Git menyimpan seluruh basis data riwayat proyek di lokal (komputer sendiri), sehingga kita tetap bisa `commit`, melihat riwayat, dan berpindah `branch` secara *offline*.
- **Hapus Repo Fork:** Menghapus repositori hasil *fork* di akun kita **tidak akan mempengaruhi** repositori asli (*upstream*).
